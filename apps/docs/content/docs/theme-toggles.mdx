Each toggle is a single client component that reads and updates the theme with `useTheme` from `@wrksz/themes/client`. They use shadcn/ui color tokens (`bg-accent`, `text-muted-foreground`, `border-input`), so they drop into a shadcn project as-is. Without shadcn, copy the file and map those tokens to your own colors.

The previews on this page control this site's theme.

## Icons

All toggles import their icons from one file, `theme-icons.tsx`. The shadcn CLI installs it with the first toggle you add. It uses [Hugeicons](https://hugeicons.com) by default; to use another icon library, change the four exports in this file and the toggles follow. In a shadcn project, `npx shadcn@latest migrate icons components/theme-icons.tsx` does it for you and asks which library to switch to.

## Requirements

- A `ThemeProvider` above the toggle.
- `enableSystem` for the system option in the switcher, select and cycle. It is on by default.
- For the theme toggle, `attribute="class"` with Tailwind's `dark:` variant on the `.dark` class, the shadcn default.
